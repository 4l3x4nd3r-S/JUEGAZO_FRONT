# Juegazo — Front web (Vite + React + Tailwind)

Proyecto base **responsivo** con **modo claro/oscuro**, enrutamiento y un **Dashboard para dueños**.
Incluye páginas: landing, canchas, reservar, dueños y dashboard.

## Requisitos
- Node.js 18+

## Instalación
```bash
npm i
npm run dev
```

## Tecnologías
- Vite + React + TypeScript
- Tailwind (con variables HSL para claro/oscuro)
- React Router
- lucide-react (iconos)

## Notas de diseño
- Paleta: verde Juegazo (brand), neutros accesibles en ambos temas.
- Tipografía del sistema para carga rápida.
- Componentes con `rounded-2xl` y `shadow-soft` coherentes con la marca.
